second_brain

A tiny command-line notebook. Jot a thought down, see what you've saved, and read it back. Every note is a plain markdown file you own.

✏️ new saves a thought 📋 list numbers your notes 👀 show reads one back

The command is just sb, short for second brain.

① Straight from --help

Three commands, one loop

Here is what the app says about itself. Click a command name in the terminal to jump to its card.

~ zsh
$ sb --help
Usage: sb [OPTIONS] COMMAND [ARGS]...

  sb -- capture and organise your thoughts.

  Notes are plain markdown files, stored in the directory named by the
  SECOND_BRAIN_DIR environment variable (default: ~/second_brain/). Commands
  print their result on stdout; log lines go to stderr.

  Typical workflow:
    sb new "Caching idea"     # save a note, prints its path
    sb list                   # numbered list, newest first
    sb show 1                 # print note 1

  Run `sb COMMAND --help` for details and examples.

Options:
  --help  Show this message and exit.

Commands:
    List all notes in the notes directory.
     Create a new note with the given TITLE.
    Display the contents of note NUMBER.

new

Create a note
💡➜📄➜📁
2026-10-25-caching-idea.md
sb new --body TEXT TITLE
  • Saves YYYY-MM-DD-<slug>.md and prints its path.
  • Never overwrites anything. A repeat title gets -1, -2, …
  • -b / --body adds more text. --body - reads it from stdin.
  • If the title has newlines, line 1 becomes the heading and the rest joins the body.

How a note is born 🐣

split_title_body()

        
First non-blank line of the title is the heading. Any other lines go in front of the body.

        

      

      

        
🔤

        
slugify()

        
Lowercase, accents folded (é→e), symbols dropped, spaces become dashes. Non-Latin scripts are kept.

        

      

      

        
📅

        
build_note_path()

        
Today's date + slug. If that file already exists, adds -1, -2, … so nothing is overwritten.

        

      

      

        
💾

        
create_note()

        
Writes # heading, the body and a timestamp as UTF-8, then returns the full path.

    ⑤ Settings
    
Knobs you can turn 🎚️

    
Three environment variables control the app. Put them in .env and run uv run --env-file .env sb …, or set them inline.

    

      
📁
SECOND_BRAIN_DIR
default: ~/second_brain/
Where notes live. It's read fresh on every command, so SECOND_BRAIN_DIR=/tmp/scratch sb list just works.

      
🔊
LOG_LEVEL
default: INFO
How chatty stderr is. DEBUG shows the extra detail. Try the dropdown in the playground.

      
📜
LOG_FILE
default: app.log
Every DEBUG+ line also goes to this file. It rotates at 50 KB. The path is relative to wherever you run the command.

    

    

      
stdout 🟢
The answer: a note's path, the list, or a note's text. Safe to pipe: sb show 1 | less

      
⇄two streams

      
stderr 🩷
The chatter: compact log lines like 2026-10-25 09:12:00 | INF | second_brain.cli:new:60 | Created note: …
